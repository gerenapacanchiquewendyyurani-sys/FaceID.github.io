PROYECTO TAILWIND CSS — RECONOCIMIENTO FACIAL
================================================

IMPORTANTE: abre el archivo index.html que está directamente dentro de esta carpeta. No abras el ZIP sin extraerlo.

ARCHIVOS INCLUIDOS
- index.html: página web completa.
- img/rostro-reconocimiento.jpg: imagen principal del rostro con marcadores faciales.
- img/logo-faceid.svg: logotipo del proyecto.
- img/icon-huella.svg, img/icon-rapidez.svg e img/icon-seguridad.svg: iconos usados en las secciones.
- paleta-colores.png y Guía visual de Tailwind CSS y FaceID.png: referencias visuales.
- tailwind-clases-guia.txt: guía de clases Tailwind.

CÓMO EJECUTAR
1. Descarga y extrae el ZIP completo.
2. Entra en la carpeta Proyecto_Tailwind_Reconocimiento_Facial_Completo.
3. Comprueba que index.html y la carpeta img estén al mismo nivel.
4. Abre index.html con Chrome, Edge o Firefox.
5. Para que se vean los estilos Tailwind, conecta el computador a Internet (se usa el CDN oficial).

IMÁGENES
Las imágenes de la página están guardadas localmente en la carpeta img; las etiquetas img del HTML usan rutas relativas como img/rostro-reconocimiento.jpg. No hace falta descargarlas por separado. Si mueves index.html fuera de esta carpeta, las rutas dejarán de coincidir.

NOTA DE PRIVACIDAD
Esta página es una maqueta académica. No activa la cámara, no identifica personas ni procesa datos biométricos reales.
